# Psicologia-segun-una-adolescente
Hola! Aquí hablo sobre lo que siento, lo que pienso y todo eso que casi nadie explica sobre la adolescencia. Tal vez no tenga todas las respuestas, pero sí muchas preguntas y experiencias en las que más de uno se puede identificar. Si alguna vez te has sentido confundido, intenso o simplemente diferente… este espacio también es para ti.
